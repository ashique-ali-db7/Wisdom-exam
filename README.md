# React Exam Platform

A comprehensive exam platform for children built with React, Vite, and Tailwind CSS.

## Features

- Child-friendly UI for students
- Professional admin interface
- Exam management system
- Question bank with MCQ and text questions
- Results tracking
- Mobile-responsive design

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```
